# XuanLoc_food_delivery

Tài liệu đặc tả và đề xuất cho dự án giao đồ ăn Xuân Lộc.

## Nội dung

- `Proposal.md` – Đề xuất dự án chi tiết (kiến trúc, scope MVP, timeline, chi phí, rủi ro).
- `Proposal_Short.md` – Bản tóm tắt đề xuất.
- `SRQ.md` – Software Requirements Specification (yêu cầu phần mềm).
- `assets/` – Hình ảnh minh hoạ.

## Trạng thái

Dự án đang ở giai đoạn đặc tả & thiết kế, chưa có mã nguồn ứng dụng.
